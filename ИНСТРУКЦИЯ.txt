САЙТ НА VERCEL: ОБЩАЯ БАЗА ВОДИТЕЛЕЙ (без Google, без пароля)
============================================================

Что в папке:
  index.html          — сайт (тот же интерфейс)
  api/handler.js      — сервер базы (работает внутри Vercel)
  package.json        — настройки
Водители и фото документов хранятся в самом Vercel (хранилище Vercel Blob).
Все диспетчеры видят один и тот же список.
ВНИМАНИЕ: пароля нет — любой, кто знает адрес сайта, увидит базу и сможет удалять водителей.

ШАГ 1. GitHub (репозиторий s-takci)
  Файлы должны лежать в репозитории так:
      index.html
      package.json
      api/handler.js        ← обязательно внутри папки api
  Как загрузить: на странице репозитория «Add file» → «Upload files» →
  перетащите из Проводника index.html, package.json и ВСЮ ПАПКУ api целиком → «Commit changes».
  Старые файлы от Netlify (api.mjs, netlify.toml) не мешают, но их можно удалить.

ШАГ 2. Vercel — подключить репозиторий
  1. Откройте https://vercel.com → «Sign Up» / «Log In» → «Continue with GitHub».
  2. «Add New…» → «Project» → рядом с s-takci нажмите «Import».
     (Если репозитория нет в списке — «Adjust GitHub App Permissions» и разрешите доступ к s-takci.)
  3. Framework Preset: «Other». Ничего больше не меняйте → «Deploy».

ШАГ 3. Vercel — подключить хранилище (без этого база не сохраняет)
  1. Откройте проект → вкладка «Storage» → «Create Database» (или «Create») → «Blob».
  2. Имя любое, например taxipark-blob. Доступ (Access): «Public». → «Create».
  3. Подключите хранилище к проекту (Connect / Connect Project), отметьте все окружения
     (Production, Preview, Development) → «Connect».
  4. Вкладка «Deployments» → у последнего деплоя «…» → «Redeploy» → «Redeploy».

ШАГ 4. Готово
  Откройте адрес проекта (вида https://s-takci.vercel.app).
  Если в браузере были водители, добавленные раньше:
  «База / Экспорт» → «Перенести в общую базу».

ДАЛЬШЕ
  • Любое изменение файлов в GitHub → Vercel сам обновит сайт через минуту.
  • «База / Экспорт» → «Скачать CSV файл» — вся база в Excel.

ЕСЛИ НЕ РАБОТАЕТ
  • «Не подключено хранилище Blob» — не сделан шаг 3 (или не нажали Redeploy).
  • «Сервер базы не отвечает» — файл handler.js лежит не в папке api.
