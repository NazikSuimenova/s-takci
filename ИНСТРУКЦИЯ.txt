ОБЩАЯ БАЗА ВОДИТЕЛЕЙ ВНУТРИ САЙТА (без Google, без пароля)
=========================================================

Что в папке:
  index.html                     — сайт (тот же интерфейс)
  netlify/functions/api.mjs      — сервер базы (работает внутри Netlify)
  package.json, netlify.toml     — настройки для Netlify

Водители и фото документов хранятся в самом сайте на Netlify (Netlify Blobs).
Все диспетчеры видят один и тот же список. Пароль не нужен — сайт открывается сразу.
ВНИМАНИЕ: любой, кто знает адрес сайта, увидит базу и сможет удалять водителей.
Не публикуйте ссылку в открытом доступе.

ШАГ 1. Загрузка на Netlify (один раз ≈ 10 минут)
  ВАЖНО: просто перетащить index.html нельзя — сервер базы не загрузится.
  Нужно загрузить всю папку через программу Netlify:

  1. Установите Node.js (версия LTS) с сайта https://nodejs.org — «Далее, Далее, Готово».
  2. Откройте папку taxipark-site в Проводнике. В адресной строке папки
     напишите  cmd  и нажмите Enter — откроется чёрное окно.
  3. Введите по очереди (после каждой строки Enter, ждите окончания):
        npm install
        npx netlify-cli login
          → откроется браузер, нажмите «Authorize»
        npx netlify-cli link
          → выберите «Search by full or partial site name» → введите taxipark → выберите сайт
        npx netlify-cli deploy --prod
  4. В конце появится «Deploy is live!». Готово.

  Потом, если что-то меняете на сайте, повторяйте только последнюю команду:
        npx netlify-cli deploy --prod

ШАГ 2. Старые записи
  Если в браузере уже были водители, добавленные раньше (до общей базы):
  кнопка «База / Экспорт» → «Перенести в общую базу».

КАК ЭТО РАБОТАЕТ
  • «Сохранить в базу» → водитель сразу попадает в общий список.
  • Фото документов хранятся на сервере сайта.
  • Список у всех обновляется сам раз в минуту (и при возврате на вкладку).
  • «База / Экспорт» → «Скачать CSV файл» — вся база в Excel.
  • Удаление водителя удаляет и его фото.

ЕСЛИ НЕ РАБОТАЕТ
  • «Сервер базы не отвечает» — сайт загружен без папки netlify.
    Сделайте шаг 1 через команду deploy, а не перетаскиванием.
